# ESP32-CYD-Duino-Coin-Miner-Dashboard
This project was built to see exactly how far a $15 microcontroller could be pushed. It is a dual-core Duino-Coin miner for the ESP32 Cheap Yellow Display that solves memory leaks and Watchdog crashes to achieve a massive 27.1 kH/s. Features include a live ECG hashrate graph, API balance fetching, and wireless OTA flashing.
